### Настройка групп срезов (GUI)

В разделе **Smooth curve approx** (группа А — ведущие кривые):
- **Fit mode** = `approximate` — кривая упрощается и укладывается в `Max deviation (mm)` (сварка/детали).
- **Max deviation (mm)** — допустимое отклонение от исходника (0 = точное следование).
- **Curve tension** — натяжение сплайна (0.0 = прямые хорды, 1.0 = плотный изгиб).
- **Overall inertia** — инерция: 0.0 = точное следование каждой точке, 1.0 = вырождение в окружность.
- **Chord tolerance (mm)** — адаптивная детализация (меньше = больше точек на изгибах).

В разделе **Tube path (group B)** (группа Б — траектория центра прутка):
- **Rod radius (mm)** — радиус прутка; центр линии смещается на это расстояние от(group A) по касательной.
- **Offset side** — `outer` (снаружи проведения), `inner` (внутри), `center` (без смещения).
- **Use cross-sections** — включает поперечные плоскости через каждый срез группы А для расчёта точек касания с соседними силуэтами.
- **Cross-section step (mm)** — шаг между поперечными срезами вдоль кривой группы А.
- **Guide group tag** — тег, по которому находятся направляющие(group A) из других срезов.
- **Contact tolerance (mm)** — допуск при аппроксимации конечной кривой группы Б через точки касания.
