# Замечания 0.2.1 и их статус

| № | Замечание | Статус в 0.3.0 |
| --- | --- | --- |
| 1 | отступ внутрь/наружу на уровне движка | `Slice.offset_mm` + `offset_contour` |
| 1.1 | X наружу, Z внутрь, минимум по радиусу сечения | `CutOffsetPolicy` |
| 2 | точки соприкосновения для сварки | `spatial/contacts.py` |
| 3 | совместная визуализация итераций | `SliceLayer` / `LayerStore` |
| 4 | неодинаковые радиусы срезов куба | `collapse_collinear` + регрессионный тест |
| 5 | многопоточность на клиенте, с fallback | `EngineClient` + `engine/parallel.py` |

Ниже — исходные формулировки.

1) Не нравится, что вручную надо подбирать размер 3d модели
2) не нравится, что если нерпавильно подобрать размер модели, то не будет auto spacing и срезы будут где попало, при этом не будут равномерно распределены по модельке (от верха до низа, а где-то в середине)
3) не хватает многопоточности в блендере, по идее движок может быть вызываем через функции. 
4) Хотелось бы, чтобы среда с визуализацией кривых позволяла визуализировать одновременно кривые от различных моделей или на одной модели, чтобы я мог видеть, как именно выглядят различные срезы

> Слои (`SliceLayer`/`LayerStore`) закрывают и это: у каждого плана свой
> слой, слои видны одновременно и независимо включаются/выключаются.
